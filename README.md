# Свадебная галерея — Артур и Анастасия

Сайт свадебной фотогалереи на Go.

Дата свадьбы: 14.07.2026

## Запуск

Установи Go 1.25 или новее.

Затем в папке проекта:

```bash
go run .
```

Открой:

http://localhost:8080

## Фотографии

Положи фотографии в:

```text
static/photos/
```

И назови их:

```text
001.jpg
002.jpg
003.jpg
...
```

Количество фотографий указывается в `main.go` в массиве `photos`.

Например:

```go
photos := []Photo{
    {Number: 1, File: "001.jpg"},
    {Number: 2, File: "002.jpg"},
}
```

## Возможности

- адаптивная галерея;
- красивый первый экран;
- полноэкранный просмотр;
- стрелки;
- клавиши ← →;
- закрытие по Escape;
- свайп на телефоне;
- lazy loading фотографий;
- фотографии хранятся локально;
- сервер написан на Go.
