# Wedding Gallery
Фотографии и музыкальный файл не входят в Git-репозиторий.

После клонирования проекта необходимо создать:

```text

static/

├── photos/

│   ├── photo1.jpg

│   ├── photo2.jpg

│   └── ...

└── music/

    └── wedding.mp3

    
Веб-приложение для просмотра свадебной фотогалереи, разработанное на Go.

Проект создан как pet-project для практики backend-разработки, работы с HTTP, HTML-шаблонами, файловой системой, Linux-сервером и deployment Go-приложения на VPS.---

Адаптивная веб-галерея с полноэкранным просмотром фотографий.

Пользователь может:

- просматривать фотографии;
- открывать фотографии в полноэкранном режиме;
- переключаться между фотографиями;
- использовать навигацию с клавиатуры;
- листать фотографии свайпами на мобильных устройствах;
- включать фоновую музыку;
- пользоваться галереей на компьютере, планшете и смартфоне.
### Backend

- `net/http`

### Frontend
